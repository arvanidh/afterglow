# AFTERGLOW

> One thumb vs ten thousand shadows.

A neon arcade roguelite for Android, solo-developed in Godot 4.
You are the last light in a city that went dark. Survive the night, bank the glow, outshine your previous run.

**Status:** pre-alpha · design locked · development started August 2026
