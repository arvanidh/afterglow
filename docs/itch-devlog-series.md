# AFTERGLOW — itch.io Devlog Series v1.0

> Companion to `devlog-content-calendar.md` (which handles short-form video). This series is the **long-form spine**: five devlogs from first prototype to open beta, posted on the free itch.io page.
> **Format law:** every post = one GIF above the fold, ≤600 words, one honest number, one clear ask. Written to be read in under 3 minutes.

---

## Writing rules

- **Titles are concrete:** numbers, stakes, or confessions — never "Devlog #3."
- **One ask per post:** follow the page *or* join Discord *or* play the build. Never all three.
- **Show the ugly:** early grey-box footage performs better than polished trailers on itch — it signals "joinable journey," not "finished ad."
- **Every post ends with the same signature:** *"— [name], solo dev, zero dollars spent so far."* The running budget gag becomes a brand.
- Cross-post each post's skeleton as a TikTok script (calendar handles scheduling).

## Publishing mechanics

- **Cadence guardrail:** never more than one devlog per month — scarcity keeps open rates high; the TikTok calendar carries weekly contact.
- **Each post auto-feeds:** Discord #devblog webhook + a TikTok script slot in the calendar week.
- **Title A/B:** if a post underperforms median views in 48h, retitle once (titles are cheap; posts are not).
- **Series arc check:** Post 1 promises transformation → Post 2 delivers it → Posts 3–5 escalate access (vote → influence → play). Never break the arc by skipping a promised reveal.
